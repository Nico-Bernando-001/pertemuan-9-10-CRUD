                           ↓
┌─────────────────────────────────────────────────────────────┐
│ 2. User ketik tahun "2025" di input                          │
│    → JS event 'input' → fetch contoh_generate_nim.php?      │
│       id_prodi=5&tahun=2025                                 │
│                                                              │
│    Server (contoh_generate_nim.php):                         │
│    ┌───────────────────────────────────────────────────┐    │
│    │ a. SELECT kode_prodi FROM program_studi            │    │
│    │    WHERE id_prodi=5     →  '42'                    │    │
│    │                                                    │    │
│    │ b. SELECT MAX(nomor_urut) FROM mahasiswa           │    │
│    │    WHERE id_prodi=5 AND tahun_angkatan=2025        │    │
│    │    → NULL (belum ada)                              │    │
│    │                                                    │    │
│    │ c. next_urut = 0 + 1 = 1                           │    │
│    │ d. NIM = "42" + "2025" + "001" = "422025001"       │    │
│    └───────────────────────────────────────────────────┘    │
│                                                              │
│    Response JSON: {"nim":"422025001","urut":1}              │
│    → nimInput.value = "422025001"  (tampil di form)         │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│ 3. User isi nama, email, password, lalu klik Simpan         │
│                                                              │
│    Form submit POST ke contoh_tambah.php.                    │
│    PAYLOAD: {nama, email, password, tahun_angkatan=2025,     │
│              id_prodi=5}                                     │
│    ⚠️  NIM TIDAK ikut terkirim (karena tidak punya name attr)│
│                                                              │
│    Server (contoh_tambah.php):                               │
│    ┌───────────────────────────────────────────────────┐    │
│    │ 1. Validasi field                                  │    │
│    │ 2. Hitung ulang: contoh_buatNIM(conn, 5, 2025)     │    │
│    │    a. kode_prodi = '42'                            │    │
│    │    b. MAX(nomor_urut) = NULL → next = 1           │    │
│    │    c. NIM = "422025001"  ← server-side, terpercaya │    │
│    │ 3. INSERT INTO mahasiswa                           │    │
│    │    (nim='422025001', ..., tahun=2025,              │    │
│    │     nomor_urut=1, id_prodi=5)                      │    │
│    │ 4. redirect ke contoh_index.php                    │    │
│    └───────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│ 4. User lain buka form, pilih prodi yang SAMA + tahun SAMA  │
│    → fetch: id_prodi=5&tahun=2025                          │
│    → MAX(nomor_urut) = 1  (dari data submit sebelumnya)    │
│    → next = 2                                              │
│    → NIM = "42" + "2025" + "002" = "422025002"  ✅         │
└─────────────────────────────────────────────────────────────┘
